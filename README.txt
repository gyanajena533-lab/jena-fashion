JENA FASHION UPDATED WEBSITE

1. Make a backup copy of your existing JENA_FASHION folder first.
2. Extract this ZIP.
3. Copy app.py, requirements.txt, templates and static into your project folder.
4. Open the project folder in VS Code.
5. Select Terminal > New Terminal.
6. Run: python -m pip install -r requirements.txt
7. Run: python app.py
8. Open: http://127.0.0.1:5000

Included: responsive Flipkart-inspired storefront, product search, category filter, price sorting and browser-local wishlist. No shopping bag/cart.

This is a front-end storefront only. It does not yet include real customer accounts, admin, database, orders or payment processing. Product photos load from Unsplash and need internet access.
